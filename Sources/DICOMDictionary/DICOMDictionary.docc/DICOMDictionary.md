# ``DICOMDictionary``

DICOM data element dictionary, UID registry and Storage SOP Class list, generated from the DICOM 2026a standard text.

## Overview

DICOMDictionary carries three tables and the lookups over them:

- **Data Element Dictionary** (``DataElementDictionary``): every element of PS3.6 Tables 6-1, 7-1, 8-1 and 9-1 and the command elements of PS3.7 Tables E.1-1 and E.2-1, with name, keyword, VR, VM and retired flag. Repeating groups (50xx Curve, 60xx Overlay) resolve to their base group.
- **UID Registry** (``UIDDictionary``): every UID of PS3.6 Table A-1 — Transfer Syntaxes, SOP Classes, Meta SOP Classes, Well-known SOP Instances, Coding Schemes, Service Classes and more — typed by ``UIDType``.
- **Storage SOP Classes** (``StorageSOPClass``): the Storage Service Class SOP Classes of PS3.4 Table B.5-1 (current) and B.6-1 (retired), shared by the C-GET SCU, the Storage SCP and the validator.

The data files are generated by `Scripts/generate_full_dictionary.py`, `Scripts/generate_uid_dictionary.py` and `Scripts/generate_storage_sop_classes.py` from the NEMA DocBook, and `Scripts/diff_dictionary.py` re-checks them row by row.

## Example Usage

```swift
import DICOMCore
import DICOMDictionary

// Look up a tag
if let entry = DataElementDictionary.lookup(tag: Tag(group: 0x0010, element: 0x0010)) {
    print(entry.keyword)   // "PatientName"
    print(entry.vr)        // [PN]
    print(entry.vm)        // "1"
}

// Look up by keyword
if let entry = DataElementDictionary.lookup(keyword: "StudyDescription") {
    print(entry.tag)       // (0008,1030)
}

// Look up a UID
if let entry = UIDDictionary.lookup(uid: "1.2.840.10008.5.1.4.1.1.2") {
    print(entry.name)      // "CT Image Storage"
    print(entry.type)      // sopClass
}

// Is this a Storage SOP Class?
StorageSOPClass.isStorage("1.2.840.10008.5.1.4.1.1.88.67")   // true (X-Ray Radiation Dose SR Storage)
```
